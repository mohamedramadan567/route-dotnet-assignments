# LINQ – Route .NET Backend Diploma

This folder contains my assignments, exercises, and practice work from the **LINQ course** in the Route .NET Backend Diploma.

The course focuses on mastering **Language Integrated Query (LINQ)** in C#, learning how to efficiently query and manipulate data collections using a clean, readable, and functional programming style.

---

* Data Types Review

  * `var`, `dynamic`, and `object`
  * Implicit typing vs runtime typing
  * Differences, use cases, and best practices

* LINQ Foundations

  * What is LINQ?
  * Why use LINQ?
  * Query syntax vs Method syntax
  * Lambda expressions recap
  * Extension methods recap

* Deferred vs Immediate Execution

  * How LINQ queries execute
  * Deferred execution concept
  * Immediate execution methods
  * `ToList()`, `Count()`, `First()` and related operators

* Filtering Operators

  * `Where`
  * `OfType`
  * `Cast`

* Projection Operators

  * `Select`
  * `SelectMany`

* Ordering Operators

  * `OrderBy`
  * `OrderByDescending`
  * `ThenBy`
  * `ThenByDescending`
  * `Reverse`

* Practice and exercises

  * Predict-the-output challenges
  * LINQ problem solving exercises
